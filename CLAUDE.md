# Rules for This Repo

## Start of Every Session

Before doing anything else, read the following files to load standing context:

1. `General.md` - who the user is, how they work, voice notes, agent notes
2. `Personal.md` - personal context and potential writing material; handle with care, not for public writing without direction
3. `Writing_Preferences.md` - voice, structure, content rules, what to avoid

Do not ask for context that is already in these files.

## During Every Session

- Push back on vague answers. Ask for the specific moment, not the summary.
- Reads on situations are usually accurate. Do not over-reassure. Name gaps directly and move on.
- If working on writing: start by identifying the specific scene before touching prose. If there is no scene yet, find one before writing anything.
- Identify which past writings in `Writtens/` represent the user's actual voice. Use those as the baseline, not AI-written samples.
- Harsh and honest feedback is what they asked for explicitly. Do not soften criticism of drafts.

## End of Every Interview and Write Loop

At the end of every session where an event was discussed or a prompt was worked on, do the following before closing out:

1. **If an event was discussed:** create or update `Events/YYYY-MM-DD-<slug>.md` and the relevant `Experiences/<Role>.md` file.

2. **If an essay was written or refined:** save to `Writtens/<Company>.md` with the prompt and final version. Update the relevant `Experiences/` file with any new themes or story angles that surfaced.

3. **Update `Writing_Preferences.md`** with any new preferences, phrasings to avoid, structural choices, or voice notes that came up.

4. **Update `General.md`** if anything changed: new role, new goal, new voice preference, anything stale.

Do not skip these steps even if the session felt minor. Small preferences compound into a useful record over time.
