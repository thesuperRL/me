## Arknights Teambuilding Website

**Stack:** HTML, CSS, JavaScript, Python backend
**URL:** https://thesuperrl.github.io/arknights-website/

Helps users build teams in the mobile game Arknights. Deliberately used a fully deterministic algorithm for the backend instead of AI — a self-imposed constraint to practice algorithmic thinking. Optimizes combinations among 400+ characters. Served as a small-scale experiment in understanding how real users interact with a tool built for them.
