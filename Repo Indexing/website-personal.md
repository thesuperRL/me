## thesuperRL.github.io

### Design Decisions

- Originally a high school web development class project (Spring 2023): class exercises in CSS, CSS Grid, Bootstrap, and JS alongside a personal "favorite thing" gallery and a Genius-lyrics-style page.
- Evolved into a hosted Sekai Heardle game: a daily music-guessing game based on Project Sekai (a Hatsune Miku rhythm game). Songs are loaded from a `songs_URL.json` file; the game plays short audio clips and the player guesses the song.
- Features: daily puzzle mode (UTC-local date conversion), endless mode (added 2026-08-06 but noted as breaking the info display), answer reveal, countdown timer, song URL management.
- Sekai Heardle Plus was added 2025-08-04 as an expanded version.
- A `TheForgottenTrail.html` page exists separately, possibly a game or story project.
- A `GFGTemp.html` was added July 2024, likely related to GFG-Unity development.
