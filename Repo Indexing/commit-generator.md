# commit-generator (git-aicommit)

**Owner:** thesuperRL
**Platform:** GitHub
**Nature:** A Rust CLI tool that reads staged git changes, sends them to a free LLM via OpenRouter or Gemini, and opens the suggested commit message in your editor before committing. Installed as a git subcommand (`git aicommit`). Every commit in the repo itself was generated by the tool.
**Language(s):** Rust
**Active period:** 2026-06-08 - 2026-06-27
**Fork of:** Original

## Design Decisions

- Async Rust via Tokio; single binary compiled with `cargo build --release` and dropped on `PATH` as `git-aicommit` so git discovers it as a subcommand.
- Config loaded in layers: `~/.config/git-aicommit/.env` first, then a per-repo `.env`, then CLI flags. Uses `dotenvy` for `.env` parsing and `clap` with `env` feature so every flag has an env-var fallback.
- Default model: `google/gemma-4-31b-it:free` via OpenRouter (zero cost). Can switch to Gemini with `--provider gemini`.
- Context assembly (`prompt.rs`): reads `git status`, changed file list, staged file contents (capped at 6 KB), repo context files like README/manifests (capped at 4 KB), and `git diff --staged`. Lockfiles and binaries are stripped before sending.
- LLM request in `llm.rs`: single POST to `/chat/completions` with `temperature=0.2`, `max_tokens=200`. Validates the response: subject must be under 30 words, optional body under 100 words, blank line required between them, no markdown fences or headings.
- Retry and fallback logic: on rate limit (429) with `--retry-forever`, fetches the full OpenRouter free-model list, sorts by parameter count (smaller models ranked first via `fallback_speed_rank`), and rotates through them every 3 failed attempts.
- Three commit modes: interactive (opens `git commit -e -F <tempfile>`), `--fast` (commits immediately), `--dry-run` (prints message only).
- `--context / -c` flag includes the previous commit's message, changed files, and diff for continuity across related commits.
- Includes an MCP server in `mcp/` for integrating with Cursor, added in the final commit.
